Official kernel-selection behavior
----------------------------------

Raspberry Pi documentation states:

- The normal 32-bit kernel default for Raspberry Pi 2, 3, 3+, and Zero 2 W is kernel7.img.
- Setting arm_64bit=1 makes firmware choose the appropriate 64-bit kernel, such as kernel8.img.
- An explicit kernel= option overrides automatic selection.
- Raspberry Pi Zero 2 W supports arm_64bit.
- The Zero 2 W 64-bit kernel build is kernel8.

Sources:

- https://www.raspberrypi.com/documentation/computers/config_txt.html#kernel
- https://www.raspberrypi.com/documentation/computers/config_txt.html#arm_64bit
- https://www.raspberrypi.com/documentation/computers/linux_kernel.html
