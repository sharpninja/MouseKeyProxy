# Historical Documentation

This directory preserves point-in-time project records that are useful for auditability but are not current product guidance.

- `plans/` contains superseded implementation and release plans.
- `audits/` contains dated code, requirements, and attribution audits.
- `handoffs/` contains completed hardware and implementation handoffs (including archived root `HANDOFF.md` notes such as the 2026-07-16 Pi Zero W ARMv6 stop).
- `receipts/` contains build, review, test, hardware, provisioning, and transition evidence.
- `requirements-exports/` contains superseded MCP requirement export receipts.
- `snapshots/` contains retired workspace or project snapshots, including the Fresh sunset archive.

Use the repository root `README.md`, current guides under `docs/`, and live requirement documents under `docs/Project/` for current behavior.
