Scope and limitations
---------------------

- QEMU's raspi3b machine was used because it models a Cortex-A53 Raspberry Pi 3-class system, the same CPU generation used by Raspberry Pi Zero 2 W.
- This is not an exact Raspberry Pi Zero 2 WH firmware, LED, Wi-Fi, Bluetooth, or USB OTG/gadget emulation.
- The raw disk was always attached with snapshot=on; QEMU did not persist writes to the source image.
- The official image's kernel8.img is gzip-compressed. QEMU direct kernel loading required the decompressed ARM64 Image.
